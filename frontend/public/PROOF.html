What this proves to a non-technical observer

  • Inputs on the left ≠ data on the right. The strings on the right (enc:v1:<iv>.<ciphertext>) are what a database administrator, a hacker, or anyone with a database dump would see.
  • Even the same input twice produces different ciphertext (every record gets a fresh 96-bit IV). Try clicking Encrypt twice with the same Full Name — outputs differ.
  • Decrypt requires the key. The Decrypt button only works in this browser tab because the key lives here. Refresh the page → new key → old ciphertext becomes unreadable.
  • Bank ID is also hashed (SHA-256 + per-event salt) as dedupeHash so the database can detect duplicates without ever seeing the plain Bank ID.
  • maskedName shows only initials. That is what the operator sees by default in the dashboard before clicking "Reveal".
